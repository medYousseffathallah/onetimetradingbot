# BVMT Competition Rules

Work from the BVMT repository root. If the repository is unavailable, request its
path or files; do not invent project state or claim commands were executed.


1. Read docs/COMPETITION_RULES_CHECKLIST.md and configs/competition.json.
2. Confirm the document governs the entered edition; preserve source and retrieval metadata.
3. Map each fact to value, status, source, exact locator, reviewer and timestamp.
4. Keep unresolved facts null. Do not promote previous chat text or research assumptions.
5. Run the rules checker and add tests for malformed, incomplete and conflicting evidence.
6. Report unresolved questions and the implications for simulation separately from strategy.
A ready-for-review result is not trading permission. Never submit orders or automate forms.
