# Custom skills

Canonical sources live here; install project copies with scripts/install_skills.py.
Each skill is independently packaged under skill-packages/<name>/skill.zip.

- `bvmt-project-bootstrap`: BVMT Project Bootstrap.
- `bvmt-data-engineering`: BVMT Data Engineering.
- `bvmt-competition-rules`: BVMT Competition Rules.
- `bvmt-backtest-validation`: BVMT Backtest Validation.
- `bvmt-model-validation`: BVMT Model Validation.
- `bvmt-event-research`: BVMT Event Research.
- `bvmt-risk-review`: BVMT Risk Review.
- `bvmt-test-driven-delivery`: BVMT Test-Driven Delivery.
- `bvmt-security-review`: BVMT Security Review.
- `bvmt-dashboard-review`: BVMT Dashboard Review.

Load one or two relevant skills per task, not all ten into every prompt.
